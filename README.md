# 早点睡

Android 睡觉提醒。每天到本地设定时间时检查屏幕是否处于可交互状态。亮屏时在当前应用上方居中显示约半屏的悬浮窗，熄屏时跳过。点「知道了」、熄屏或等待 60 秒即可关闭。应用无联网权限，时间和开关保存在设备本地。

## 使用方法

1. 安装 APK 后打开应用，授权「显示在其他应用上层」及「闹钟和提醒」（系统要求时）。
2. 点「预览悬浮窗」检查显示效果，然后设定时间并开启每日提醒。默认时间为 23:00。
3. 可将时间设到下一分钟，切到其他应用，验证亮屏时是否弹窗。再改到下一分钟并锁屏，验证不会弹窗或点亮屏幕。

应用在收到系统重启、应用更新、时间或时区变更等广播后重排提醒。若系统延迟超过一分钟，则跳过当次提醒。系统可能在锁屏、安全界面或明确屏蔽悬浮窗的应用上隐藏窗口。强行停止后需重新打开应用。部分厂商的后台管理也可能拦截提醒，兼容性需真机验证。

## 构建和发布

- Android 8.0 起可安装。用 Android Studio 打开此目录，配置 JDK 17、Gradle 8.11.1 和 Android SDK 35。命令行可运行 `gradle :app:assembleDebug :app:lintDebug`。
- 把此目录内容推送到自己的 GitHub 仓库后，在 Actions 的「Android APK」运行记录下载 `night-reminder-debug`。调试 APK 供试装。
- 对外发布时在 Android Studio 生成签名 APK，并将其作为 GitHub Release 附件。后续更新沿用同一应用 ID 和签名。发布前应确定应用 ID 并保管好签名密钥。商店上架另需遵循对应商店的权限及前台服务审核规则。
- iPhone 第三方应用无法在其他应用上方显示常驻或定时触发的悬浮窗，也无法在后台定时获取全局亮屏状态。本项目的半屏实现面向 Android。

## 真机验证清单

- 在 Android 8、12、14 和 15 或更新系统上验证安装、权限和弹窗。
- 验证亮屏、熄屏、点击关闭、超时、横竖屏、修改时间、关闭提醒、重启和切换时区。
- 在三星、小米、OPPO、vivo 等设备各验证一次，并记录系统版本及后台管理设置。
